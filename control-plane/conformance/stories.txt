# Conformance stories to run against the control plane, relative to the spec repo's tests/ directory.
#
# Two things must be true before a story belongs here:
#
#   1. Every chapter is within the implemented surface. A story touching an unimplemented operation
#      fails on the 501, which is correct but not useful signal.
#   2. THE STORY PASSES AGAINST A REFERENCE OPENSEARCH. Checking the paths is not enough -- a story's
#      payload can depend on a plugin that a plain cluster does not have. Verify with:
#
#        conformance/run.sh --url http://localhost:9200
#
#      pointing --url at a real cluster. If it fails there, it is not a valid target for us either.
#
# Lines starting with # are comments.
